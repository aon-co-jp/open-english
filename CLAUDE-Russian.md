## Роль этого проекта

Веб-приложение для изучения английского языка для ПК/планшета/
смартфона. В стиле «уроков английского в мейд-кафе», персонаж
девочки-волшебницы-горничной (оригинальный дизайн, анимированный)
сопровождает учащихся от новичка до продвинутого уровня. За
ИИ-ответы отвечает
[`aruaru-llm`](https://github.com/aon-co-jp/aruaru-llm).

## Архитектура (по указанию пользователя, 2026-08-10)

- **Сторона Linux (VPS)**: только сервер раздачи для скачивания.
  Управление приложением выполняет
  [`open-easy-web`](https://github.com/aon-co-jp/open-easy-web).
- **Сторона устройства пользователя**: статический веб-фронтенд этого
  репозитория + локально запускаемый нативный сервер из `aruaru-llm`
  (использует внутри бэкенды вывода `open-directx`/`open-cuda`),
  который пользователь скачивает и запускает сам. Браузер локально
  подключается (онлайн/офлайн) к `http://localhost:4600`.

## Честное раскрытие / известные ограничения (по состоянию на 2026-08-10)

- `/v1/generate` от `aruaru-llm` основан на GPT-2 (с упором на
  английский, без дообучения для диалога) — качество ответов и
  соблюдение уровня не гарантированы.
- CORS был исправлен 2026-08-10 (`.with_cors()` на стороне
  `aruaru-llm`).
- Синтез речи (TTS)/синхронизация губ для персонажей-тренеров
  подключены через Web Speech API; анимация самого персонажа-мейд
  остаётся простым CSS-циклом открытия/закрытия рта.

## Видение будущего (по указанию пользователя, 2026-08-10, ещё не начато)

Есть идея запускать `open-directx`/`open-cuda`/`aruaru-llm` также
автономно в браузере (WASM/WebGPU) и интегрировать их с `RPoem`
(платформой GraphQL Federation). Поскольку это крупное архитектурное
изменение по сравнению с текущим дизайном Фазы 0 (локальный резидентный
сервер + подключение к localhost), это будет реализовано только после
завершения MVP, с отдельным объёмом работ.

## Другие обновления (2026-08-19 — 2026-08-20)

С тех пор были добавлены, среди прочего: уведомление о достижении
дневного лимита использования со ссылками на платные тарифы и
бесплатные лимиты других провайдеров; новая панель «Data & Model
Storage» с интерфейсом резервного копирования/восстановления;
баннер, призывающий задействовать неиспользуемые смартфоны
(`PhoneAccelWorker` с определением NNAPI); совместное резервное
копирование aruaru-db/PostgreSQL через rsync; страница-заглушка
дорожной карты для консольных портов (PlayStation/Switch/Wii/Wii U,
в ожидании одобрения производителей платформ); автообновление,
расширенное на все поставляемые компоненты (aruaru-llm/aruaru-db) с
периодической проверкой каждые 6 часов и ручным откатом версии по
каждому компоненту отдельно; исправление, из-за которого aruaru-llm
теперь запускается автоматически в Windows (без ручных действий);
информационный баннер о бесплатных лимитах провайдеров ИИ/поиска
(включая Claude/Anthropic); критическое исправление, предотвращающее
потерю базы данных переписки при автообновлении/откате в Windows
(проверено сквозным тестом через реальный установщик); а также новые
функции для Android (автоматическое определение URL ПК путём
сканирования подсети, проверенное на реальном устройстве со
Snapdragon с успешным определением NNAPI, хотя само вычислительное
разгрузка через NNAPI пока не реализована). Подробности — в записях
HANDOFF от 2026-08-19 и 2026-08-20 в [CLAUDE.md](CLAUDE.md).

## Недавние обновления, связанные с установкой (2026-08-19)

Единый установщик для Windows `open-english-install.exe`; встроенное
автообновление (`server/src/self_update.rs`) расширено на Linux, а
затем на macOS, с автоматическим откатом на основе проверки
работоспособности `/healthz`, если новая версия не запускается
корректно; новая входная страница `facebook.html` для пользователей с
доступом только к Facebook (честное раскрытие: это не официальное
партнёрство с Meta); а с 2026-08-18 приложение предлагает и
автоматизирует установку `rsync`, если он отсутствует, сразу запуская
резервное копирование после установки. Полные подробности — только в
японских записях HANDOFF ниже.

ИИ-агентом, без вычитки носителем языка.)*

## Обновление 2026-08-22: пробные тесты по языкам мира, выбор языков, многоязычное озвучивание

Перед реализацией код был проверен: **никакого списка языков перевода и
таблицы i18n в проекте не существовало** (`learn-target` знал только
английский и японский). Поэтому список языков был определён заново в
рамках этой функции — **38 языков** (17 европейских, включая
ретороманский в Швейцарии, русский, 4 ближневосточных, 7
южноазиатских, 8 восточно- и юго-восточноазиатских, 1 африканский),
плюс всегда активные английский и японский.

- Новые данные: `world-language-exams.json` (оригинальные вопросы с
  выбором ответа и уровнями в стиле CEFR, 3–6 на язык) и
  `world-language-phrases.json` (5 базовых фраз × 40 языков).
- Новый API: `GET /v1/world-languages` возвращает только сводку, без
  текстов заданий. Для сохранения в БД новый эндпоинт **не** создавался
  — достаточно существующего `POST /v1/db/history`.
- Интерфейс: двуязычный баннер, панель «🌐 Languages» с флажками,
  «Выбрать все» и «Снять все, кроме EN и JA», выбор **2–5 языков**
  (ограничение обеспечивается интерфейсом), последовательный показ и
  озвучивание с любым числом повторов (целиком или по одному языку),
  копирование, скачивание .txt и сохранение в SQLite.
- После проверки ошибочные вопросы ведут к разговору с преподавателем
  соответствующего языка (повторно используется `examPrepMissedQuestions`).

**Честное раскрытие**: это оригинальные вопросы, не связанные с
официальными сертификатами; всего 3–6 заданий на язык; проверки
носителями языка не проводилось; реальное озвучивание на 38 языках не
проверено на настоящих голосах (только через наблюдающую заглушку).
Подробности — в записи HANDOFF от 2026-08-22 в [CLAUDE.md](CLAUDE.md).
