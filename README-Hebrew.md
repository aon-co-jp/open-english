## ארכיטקטורה (לפי הנחיית המשתמש, 2026-08-10)

- **צד Linux (VPS)**: רק שרת הפצה להורדה (לא המקום שבו האפליקציה
  עצמה פועלת בפועל). ניהול האפליקציה מתבצע על ידי
  [`open-easy-web`](https://github.com/aon-co-jp/open-easy-web).
- **צד מכשיר המשתמש (מחשב/טאבלט/טלפון)**: הצד הקדמי הסטטי של המאגר
  הזה (HTML/CSS/JS, פועל בדפדפן) + שרת native שפועל מקומית מתוך
  [`aruaru-llm`](https://github.com/aon-co-jp/aruaru-llm) (המשתמש
  פנימית ב-backend ההסקה של `open-directx`/`open-cuda`), שהמשתמש
  מוריד ומפעיל בעצמו. הדפדפן מתחבר מקומית (מקוון או לא מקוון) אל
  `http://localhost:4600` (הפורט ברירת המחדל של aruaru-llm) — עיצוב
  "היברידי".

## היקף נוכחי (שלב 0) — גילוי כן

- **איכות תגובות הבינה המלאכותית**: `/v1/generate` של `aruaru-llm`
  מבצע יצירת טקסט אוטורגרסיבית באמצעות GPT-2 (124M-1.5B, ממוקד
  אנגלית, ללא כוונון עדין לדיאלוג). שטף התגובה או התאמתה לרמה אינם
  מובטחים — הדבר מוצג על המסך, ללא הגזמה. החל מ-2026-08-10, קנס חזרה
  (ברירת מחדל 1.3) מתקן את באג לולאת החזרה האינסופית שדווח בעבר.
- **CORS**: תוקן החל מ-2026-08-10 — שרת ה-HTTP של `aruaru-llm` שולח
  כעת כותרות `Access-Control-*`, כך שהצד הקדמי הזה יכול להיפתח
  cross-origin (או דרך `file://`) ועדיין להגיע ל-`http://localhost:4600`.
- **בחירת רמה**: בורר הרמה ממתחיל למתקדם קיים בממשק, אך האכיפה בפועל
  של הרמה מוגבלת להוראה קצרה בפרומפט — אין ערבות ש-GPT-2 יישמע לה.
- **קול/TTS**: מחוברת Web Speech API אמיתית (SpeechSynthesis ליציאה,
  SpeechRecognition לכניסת מיקרופון), עם כוונון גובה/מהירות לכל דמות.
- **מצב אימון**: תסריט הצגה עצמית דטרמיניסטי (לא נוצר על ידי בינה
  מלאכותית) שכולל כעת גם טכניקת שיחה מבוססת מילות מפתח של קפה מייד
  אמיתי באקיהברה, וכן שלב שמסכם את הפריחה הנוכחית של התרבות היפנית
  בחו"ל.
- **סמלי הפעלה**: `icons/` + `manifest.json` (PWA) + `launchers/`
  מאפשרים להפעיל את האפליקציה מסמל שולחן עבודה (Windows/Mac/Linux) או
  מסמל מסך הבית (Android/iPhone/iPad).
- **עדכון אוטומטי**: `auto-update.js` בודק את `version.json` כל 5
  שניות וטוען מחדש את העמוד כאשר מזהה ה-build משתנה. **מגבלה ידועה**:
  חלק מהדפדפנים חוסמים `fetch()` של קבצים מקומיים תחת סכימת `file://`
  — מובטח לעבוד כאשר מוגש דרך שרת HTTP מקומי, ואחרת מושבת בשקט.

## איך להריץ

1. הפעילו את [`aruaru-llm`](https://github.com/aon-co-jp/aruaru-llm)
   עם `cargo run --release` (ברירת מחדל `http://localhost:4600`,
   מודל ברירת המחדל כעת `distilgpt2`).
2. בתיקיית `server/`, הריצו `cargo run --release` כדי להגיש את הצד
   הקדמי הסטטי של המאגר הזה בכתובת `http://127.0.0.1:4601/`
   (מבוסס RPoem — `python3 -m http.server` כבר לא נחוץ; ניתן לשנות
   פורט עם משתנה הסביבה `OPEN_ENGLISH_SERVER_BIND`).
3. פתחו את `http://127.0.0.1:4601/` בדפדפן. פתיחה ישירה של
   `index.html` דרך `file://` עדיין עובדת, אך חלק מהדפדפנים חוסמים שם
   `fetch()` ומשביתים את העדכון האוטומטי — מומלץ להשתמש בשרת מהשלב 2.
