open-english をインストールしていただきありがとうございます。

このインストーラーが導入するのは open-english の配信サーバー
(open-english-server.exe)と静的フロントエンドのみです。
AI応答を生成する aruaru-llm は別リポジトリのため、このインストーラー
には含まれていません。以下から別途ダウンロード・起動してください
(初回のみ、コマンド操作が必要です):

  https://github.com/aon-co-jp/aruaru-llm/releases

aruaru-llm 側の README/install.ps1 の手順に従って起動した後、
このアプリのショートカット(スタートメニュー / デスクトップ)を実行
すると、ブラウザが http://127.0.0.1:4601/ を開き、チャットできる
ようになります。

スマートフォン(Android)から使う場合は、この open-english アプリを
インストールしたPCと同じWi-Fi内で、Androidアプリ側にこのPCの
IPアドレス(例: 192.168.1.10:4601)を入力するだけで接続できます。
スマホ側でコマンド操作は不要です。

---

Thank you for installing open-english.

This installer only sets up the open-english file server
(open-english-server.exe) and static frontend. aruaru-llm (which
generates the AI responses) lives in a separate repository and is
not bundled here. Please download and start it separately (a one-
time command-line step) from:

  https://github.com/aon-co-jp/aruaru-llm/releases

Once aruaru-llm is running, launch this app from the Start Menu or
Desktop shortcut, and your browser will open
http://127.0.0.1:4601/ so you can chat.

To use this from a smartphone (Android), just install the open-
english Android app and enter this PC's IP address (e.g.
192.168.1.10:4601) while on the same Wi-Fi — no command-line steps
are needed on the phone.
