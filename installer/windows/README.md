# このフォルダについて / About this folder

`open-english.iss` はこのインストーラーを**作るための** [Inno Setup](https://jrsoftware.org/isinfo.php)
ビルドスクリプトです。`open-english-installer.exe` はこのフォルダ内に実体として置いてあります
(ユーザー指示により、ローカルビルドしたバイナリを直接コミット)。

**⬇ 今すぐダウンロード**: [open-english-installer.exe](open-english-installer.exe)

**正直な開示**: このファイルはビルド成果物であり、`open-english.iss`やソースコードを変更しても
自動的には更新されません(手動での再ビルド・再コミットが必要)。[常に最新版が欲しい場合は
GitHub Releasesも参照してください。](https://github.com/aon-co-jp/open-english/releases/latest)

---

`open-english.iss` is the [Inno Setup](https://jrsoftware.org/isinfo.php) build script used to
**produce** this installer. `open-english-installer.exe` itself is committed directly into this
folder (per explicit user instruction, a locally-built binary is committed as-is).

**Honest disclosure**: this file is a build artifact. It does not update automatically when
`open-english.iss` or the source code changes (a manual rebuild + recommit is required). [If you
always want the latest version, also check GitHub Releases.](https://github.com/aon-co-jp/open-english/releases/latest)
