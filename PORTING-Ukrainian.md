# PORTING.md — Посібник з перенесення open-english (скорочена версія)

> **Примітка**: це скорочений переклад. Повний технічний посібник з
> деталями коду та підводними каменями залишається доступним лише
> японською в [PORTING.md](PORTING.md) — звіряйтеся з ним перед
> фактичним застосуванням будь-якого патерну.

Короткий огляд придатних для повторного використання патернів
реалізації з цього проєкту, на випадок перенесення в інший проєкт:

1. **Патерн інтеграції з `aruaru-llm`**: вимагає підтримки CORS
   (`.with_cors()`) та штрафу за повторення
   (`generate_with_repetition_penalty`, за замовчуванням 1,3) на боці
   `aruaru-llm`, інакше браузер блокує `fetch()`, або жадібне
   декодування GPT-2 потрапляє в цикл повторень.
2. **Витягування мови для TTS** (`extractSpeechText`): розділяє
   двомовні рядки у форматі "English / 日本語" перед передачею до
   `SpeechSynthesisUtterance`, щоб уникнути переривчастої вимови.
3. **Набір іконок запуску** (`icons/` + `manifest.json` +
   `launchers/`): написаний вручну PNG/ICO-кодер без зовнішніх
   графічних інструментів, плюс скрипти для `.lnk` Windows, `.desktop`
   Linux та `.app` macOS.
4. **Автооновлення** (`auto-update.js` + `version.json`): простий
   опитувальний цикл `buildId` кожні 5с з `location.reload()`.
5. **Статичний сервер на основі RPoem** (`server/`): замінює `python3
   -m http.server` крейтом Rust, що повторно використовує
   `static_file_handler` з `open-runo-poem-compat`.
6. **Структурна гарантія гібридних відповідей** (`ensureHybridReply`):
   автоматично додає коротку примітку японською, якщо відповідь моделі
   не містить японської — без перебільшення якості перекладу.
7. **Керування версіями + очищення старих версій на боці браузера**:
   `version.json` з полем `version`, видалення власних ключів
   `localStorage` застосунку при новій версії.
8. **Міст до Google Custom Search JSON API + панель налаштувань у
   браузері**: облікові дані лише в пам'яті процесу, ніколи на диску.
9. **Інсталятор для Windows (Inno Setup) — реальні кроки перевірки**:
   `PrivilegesRequired=lowest` проти зависань UAC,
   `MSYS_NO_PATHCONV=1` для тихого встановлення з Git Bash.
10. **Гео-/туристична БД з попередженнями про безпеку, що залежать від
    теми**: пошук за підрядком замість точного збігу; для небезпечних
    тем (наприклад, альпінізм) завжди додавати попередження про
    безпеку.
11. **Автооновлення через GitHub Releases (лише Windows)**: має бути
    реалізовано на нативному боці (не в JS браузера); власний
    запущений .exe не можна видалити у Windows — спочатку запустити
    відокремлений batch-скрипт, потім завершити власний процес.
12. **CSS-класам модальних вікон потрібні `max-height`/`overflow-y`**:
    кожен клас контейнера модального вікна має визначати можливість
    прокручування, інакше довгий контент недоступний на мобільних
    пристроях.
13. **Включення Rust-сервера в Android**: робити шляхи перевизначуваними
    під час виконання через змінну середовища; завжди захищати
    специфічну для Windows логіку автооновлення через
    `cfg!(target_os = "windows")`.

**Важливе застереження**: цей проєкт — прототип Фази 0 — якість
ШІ-відповідей (на основі GPT-2), природність синтезу мовлення та
надійна відповідність рівню не гарантовані. Це також слід чітко
розкривати під час будь-якого перенесення.
