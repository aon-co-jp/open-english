# console-ports

このディレクトリは、PlayStation / Nintendo Switch(SW1/SW2) / Wii / Wii U向け
移植のための**プレースホルダー**です。Sony/Nintendo公式デベロッパー登録・
審査・NDA締結・非公開devkit入手が前提であり、現時点ではまだ許可を得て
いないため、実装コードは一切含まれていません。詳細は
[`../PLATFORM-ROADMAP.md`](../PLATFORM-ROADMAP.md)を参照してください。

This directory is a **placeholder** for potential PlayStation / Nintendo
Switch (SW1/SW2) / Wii / Wii U ports. It contains no implementation code,
because official developer registration, vetting, an NDA, and access to
non-public devkits from Sony/Nintendo are prerequisites we do not yet have.
See [`../PLATFORM-ROADMAP.md`](../PLATFORM-ROADMAP.md) for details.
