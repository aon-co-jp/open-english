# הוספת סמל למסך הבית (Android/iPhone/iPad)

open-english הוא אפליקציית ווב סטטית שאינה דורשת שרת (עם תמיכה ב-PWA manifest), כך שאין
צורך להתקין אפליקציה ייעודית מחנות אפליקציות — ניתן למקם סמל על מסך הבית באמצעות הפונקציה
"הוספה למסך הבית" של הדפדפן.

## דרישות מקדימות

- יש לפתוח את `index.html` דרך שרת ווב כלשהו (או דרך שרת ההורדות של `open-easy-web`) —
  פתיחה ישירה כ-`file://` גורמת לדפדפנים רבים לחסום את טעינת manifest.json/הסמלים,
  ואפשרות "הוספה למסך הבית" עשויה שלא להופיע. לבדיקה מקומית, לדוגמה:
  ```
  cd open-english
  python3 -m http.server 8090
  ```
  ולאחר מכן לפתוח את `http://<כתובת ה-IP של המחשב>:8090/index.html` בדפדפן הטלפון.

## Android (Chrome)

1. לפתוח את `index.html` ב-Chrome.
2. להקיש על תפריט "⋮" בפינה השמאלית העליונה ← "הוספה למסך הבית" (או "התקנה" מבאנר
   ההתקנה שעשוי להופיע אוטומטית).
3. ה-`icons` מתוך `manifest.json` (`icons/icon-192.png`, `icons/icon-512.png`) משמשים
   כסמל מסך הבית.

## iPhone / iPad (Safari)

1. לפתוח את `index.html` ב-Safari.
2. להקיש על כפתור השיתוף (הסמל המרובע עם החץ כלפי מעלה).
3. לבחור "הוספה למסך הבית".
4. `<link rel="apple-touch-icon" ...>` (`icons/icon-180.png`) משמש כסמל מסך הבית.

## גילוי נאות

- שתי השיטות יוצרות **קיצור דרך של הדפדפן (PWA), לא אפליקציה ילידית** — זו אינה התקנה
  דרך חנות אפליקציות.
- פעולה במצב לא מקוון (Service Worker) לא מומשה — עדיין נדרש חיבור רשת (מכיוון שבתכנון
  שלב 0, `aruaru-llm` הוא שרת המתגורר באופן מקומי, הגדרה זו אינה מניחה הפעלה עצמאית של
  `aruaru-llm` על הטלפון עצמו).
