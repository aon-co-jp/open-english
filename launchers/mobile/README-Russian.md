# Добавление значка на главный экран (Android/iPhone/iPad)

open-english — это статическое веб-приложение, не требующее сервера (с поддержкой PWA
manifest), поэтому нет необходимости устанавливать отдельное нативное приложение из
магазина — вы можете разместить значок на главном экране с помощью функции браузера
«Добавить на главный экран».

## Предварительные условия

- `index.html` необходимо открывать через веб-сервер (или через сервер загрузки
  `open-easy-web`) — при прямом открытии как `file://` многие браузеры блокируют загрузку
  manifest.json/значков, и опция «Добавить на главный экран» может не появиться. Для
  локального тестирования, например:
  ```
  cd open-english
  python3 -m http.server 8090
  ```
  затем открыть `http://<IP ПК>:8090/index.html` в браузере смартфона.

## Android (Chrome)

1. Открыть `index.html` в Chrome.
2. Нажать меню «⋮» в правом верхнем углу → «Добавить на главный экран» (или
   «Установить» из баннера установки, который может появиться автоматически).
3. `icons` из `manifest.json` (`icons/icon-192.png`, `icons/icon-512.png`) используются
   как значок главного экрана.

## iPhone / iPad (Safari)

1. Открыть `index.html` в Safari.
2. Нажать кнопку «Поделиться» (квадратный значок со стрелкой вверх).
3. Выбрать «На экран «Домой»».
4. `<link rel="apple-touch-icon" ...>` (`icons/icon-180.png`) используется как значок
   главного экрана.

## Честное раскрытие информации

- Оба способа создают **ярлык браузера (PWA), а не нативное приложение** — это не
  установка через магазин приложений.
- Автономная работа (Service Worker) не реализована — по-прежнему требуется сетевое
  подключение (поскольку в дизайне Phase 0 `aruaru-llm` является локально резидентным
  сервером, эта настройка не предполагает автономный запуск `aruaru-llm` на смартфоне).
