# Додавання значка на головний екран (Android/iPhone/iPad)

open-english — це статичний веб-застосунок, що не потребує сервера (з підтримкою PWA
manifest), тому немає потреби встановлювати окремий нативний застосунок з магазину — ви
можете розмістити значок на головному екрані за допомогою функції браузера «Додати на
головний екран».

## Попередні умови

- `index.html` потрібно відкривати через веб-сервер (або через сервер завантаження
  `open-easy-web`) — при прямому відкритті як `file://` багато браузерів блокують
  завантаження manifest.json/значків, і опція «Додати на головний екран» може не
  з'явитися. Для локального тестування, наприклад:
  ```
  cd open-english
  python3 -m http.server 8090
  ```
  потім відкрити `http://<IP ПК>:8090/index.html` у браузері смартфона.

## Android (Chrome)

1. Відкрити `index.html` у Chrome.
2. Натиснути меню «⋮» у верхньому правому куті → «Додати на головний екран» (або
   «Встановити» з банера встановлення, який може з'явитися автоматично).
3. `icons` з `manifest.json` (`icons/icon-192.png`, `icons/icon-512.png`) використовуються
   як значок головного екрана.

## iPhone / iPad (Safari)

1. Відкрити `index.html` у Safari.
2. Натиснути кнопку «Поділитися» (квадратний значок зі стрілкою вгору).
3. Вибрати «На головний екран».
4. `<link rel="apple-touch-icon" ...>` (`icons/icon-180.png`) використовується як значок
   головного екрана.

## Чесне розкриття інформації

- Обидва способи створюють **ярлик браузера (PWA), а не нативний застосунок** — це не
  встановлення через магазин застосунків.
- Автономна робота (Service Worker) не реалізована — мережеве підключення все ще
  необхідне (оскільки в дизайні Phase 0 `aruaru-llm` є локально резидентним сервером, це
  налаштування не передбачає автономний запуск `aruaru-llm` на смартфоні).
