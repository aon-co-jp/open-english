# افزودن نماد به صفحه اصلی (Android/iPhone/iPad)

open-english یک برنامه وب استاتیک بدون نیاز به سرور است (با پشتیبانی از PWA manifest)، بنابراین
نیازی به نصب یک برنامه بومی اختصاصی از فروشگاه نیست — می‌توانید با استفاده از قابلیت
«افزودن به صفحه اصلی» مرورگر، نمادی را روی صفحه اصلی قرار دهید.

## پیش‌نیازها

- فایل `index.html` باید از طریق یک سرور وب (یا از طریق سرور دانلود `open-easy-web`) باز
  شود — باز کردن مستقیم آن به‌صورت `file://` باعث می‌شود بسیاری از مرورگرها بارگذاری
  manifest.json/نمادها را مسدود کنند و گزینه «افزودن به صفحه اصلی» ممکن است ظاهر نشود.
  برای آزمایش محلی، برای مثال:
  ```
  cd open-english
  python3 -m http.server 8090
  ```
  سپس `http://<IP کامپیوتر>:8090/index.html` را در مرورگر گوشی باز کنید.

## Android (Chrome)

1. `index.html` را در Chrome باز کنید.
2. روی منوی «⋮» در گوشه بالا سمت راست ضربه بزنید ← «افزودن به صفحه اصلی» (یا «نصب» از
   بنر نصبی که ممکن است به‌طور خودکار ظاهر شود).
3. `icons` موجود در `manifest.json` (`icons/icon-192.png`، `icons/icon-512.png`) به‌عنوان
   نماد صفحه اصلی استفاده می‌شوند.

## iPhone / iPad (Safari)

1. `index.html` را در Safari باز کنید.
2. روی دکمه اشتراک‌گذاری ضربه بزنید (نماد مربعی با فلش رو به بالا).
3. «افزودن به صفحه اصلی» را انتخاب کنید.
4. `<link rel="apple-touch-icon" ...>` (`icons/icon-180.png`) به‌عنوان نماد صفحه اصلی
   استفاده می‌شود.

## افشای صادقانه

- هر دو روش **یک میان‌بر مرورگر (PWA) ایجاد می‌کنند، نه یک برنامه بومی** — این یک نصب
  از طریق فروشگاه برنامه نیست.
- عملکرد آفلاین (Service Worker) پیاده‌سازی نشده است — اتصال شبکه همچنان لازم است
  (از آنجا که در طراحی Phase 0، `aruaru-llm` سروری است که به‌صورت محلی مقیم است، این
  پیکربندی فرض نمی‌کند که `aruaru-llm` به‌طور مستقل روی گوشی اجرا شود).
